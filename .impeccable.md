# Design Context — Poltertty

## Target Audience
Developer power users running multiple AI coding agents (Claude Code, Gemini CLI, OpenCode) simultaneously on macOS. Technically sophisticated, keyboard-fluent, value density and speed over decoration.

## Use Cases
- **Agent Dashboard**: Real-time HUD showing all running agents' status, token usage, cost, and current task across workspaces. Users glance at it to know what's happening, click to navigate to an agent's pane.
- **Workspaces**: Managing multiple projects/worktrees in a terminal environment
- **Git panels, file browser**: Developer tooling inside a terminal emulator

## Brand Personality / Tone
**Industrial precision** — Like `htop` or a professional monitoring tool. Dense, data-rich, zero fluff. The aesthetic should feel like a tool built by engineers for engineers: monochrome-leaning with surgical use of color only for meaningful status signals. Think Bloomberg Terminal meets native macOS.

Tone keywords: **precise, dense, trustworthy, fast, native**. NOT flashy, NOT consumer-grade, NOT decorative.

## Platform Constraints
- macOS only, native SwiftUI
- Dark and light mode support (follows system)
- No web UI, no CSS — SwiftUI/AppKit conventions apply
- Floating window panel (non-modal overlay)
- Minimum width ~720px, no mobile concerns

## Differentiation
The dashboard should feel like a real system monitor: data-dense but scannable, where state changes are immediately obvious through motion and color, not just static dots. The one memorable thing: **instant visual clarity** — you know the state of every agent at a glance.
